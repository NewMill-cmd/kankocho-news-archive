# 公開用CSV

このフォルダーのデータはリポジトリ上で一般公開されます。ニュース取得プログラム全体、.env、APIキー、コメント、ユーザー情報、内部ログはアップロードしないでください。

保存先：`data/jp/YYYY-MM-DD.csv`（日本）、`data/us/YYYY-MM-DD.csv`（米国）、`data/eu/YYYY-MM-DD.csv`（欧州）。その他は `data/other/`。

ライブ自動送信版の日付は発表日です。日本版は Asia/Tokyo、米国・欧州版は既存のニュース取得プログラムに合わせ America/New_York を使用します。CSVの「日付基準」列で確認できます。

文字コードは UTF-8、1行目は列名とし各行の列数を揃えます。手動登録では `YYYY-MM-DD_suffix.csv` という英数字の接尾辞も使えます。

mainへの追加・更新後にPagesの一覧が更新されます。ライブからの送信前にExcelの数式対策を実施します。公開ページ生成時も数式対策とBOM付与を行うため、元のCSVとバイト単位で一致しない場合があります。GitHub上の手動アップロードファイルは加工されないので、アップロード前に内容を確認してください。

ライブ自動送信版の公開項目：公開日時（原データ）、公開日時（日本時間）、検知時刻（日本時間）、地域、発表元、機関コード、発表タイトル、URL、日付基準。AI会話、要約・翻訳、コメント情報は送信しません。

全件取得を保証するものではなく、公式機関とは独立した非公式アーカイブです。再利用時は各発表元の利用条件をご確認ください。
