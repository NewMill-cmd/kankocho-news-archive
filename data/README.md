# 公開用CSV

このフォルダーに登録したデータは、リポジトリ上で即座に一般公開されます。
ニュース取得プログラムのフォルダー全体、.env、APIキー、コメント、ユーザー情報、内部ログはアップロードしないでください。

保存先：`data/jp/2026-10-27.csv`（日本）、`data/us/2026-10-27.csv`（米国）、`data/eu/2026-10-27.csv`（欧州）。その他は `data/other/`。
日付はそのCSVの取得対象日（日本時間）です。日付のみの名前のほか、`2026-10-27_evening.csv` のような英数字の接尾辞も使えます。
文字コードは UTF-8、1行目は列名とし、各行の列数を揃えてください。列名は既存の公開用CSVに合わせられます。

mainにCSVを追加・更新するとPagesの一覧が自動更新されます。公開ページではExcel用の数式対策とBOM付与を行うため、元のCSVとバイト単位で一致しない場合があります。
GitHub上の元ファイルは加工されません。アップロード前の内容確認は必須です。

公開候補：発表日、検出日時、国・地域、発表機関、タイトル、公式URL、カテゴリ、AI要約（自動生成と明記）。
全件取得を保証するものではなく、公式機関とは独立した非公式アーカイブです。
